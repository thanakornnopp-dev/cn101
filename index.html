CHAPTER 5 สัปดาห์ที่ 8 • 3 & 8 ต.ค.

1. List 2, 2D Lists & List Comprehension

▶ คลิปสอน 📄 สไลด์ PDF

📌 มโนทัศน์ที่ต้องแม่น (Key Concepts)

  • List Slicing ขั้นสูง: list[start:stop:step]
    เช่น [-3:] คือเอา 3 ตัวสุดท้าย, [::-1] คือกลับด้าน
  • Nested List (2D List): ลิสต์ซ้อนลิสต์ เข้าถึงด้วย data[row][col]
    การวนลูปต้องใช้ Nested loop: ลูปนอกวิ่งตามแถว ลูปในวิ่งตามคอลัมน์
  • List Comprehension: ย่อ loop เหลือ 1 บรรทัด
    • มีแค่ if: [exp for x in lst if cond]
    • มี if-else: [exp1 if cond else exp2 for x in lst]

⚠️ จุดที่คนมักผิดในข้อสอบ (Exam Traps)

# ระวังการเข้าถึง Index ของ 2D List 
nums = [[1, 5], [6, 7]]
nums[0][0] = 9
nums[1][1] = 10
# ผลลัพธ์: [[9, 5], [6, 10]]
❌ อย่าสับสน: ตัวหน้าคือแถว (Row) ตัวหลังคือหลัก (Col) เริ่มนับจาก 0 เสมอ

2. Functions (ฟังก์ชันและการส่งค่า)

▶ Part 1 ▶ Part 2 📄 สไลด์

📌 มโนทัศน์ที่ต้องแม่น (Key Concepts)

  • Void vs Value-Returning: ฟังก์ชันที่คืนค่าต้องมี return ส่งค่ากลับไป (ถ้าไม่มี return จะคืนค่าเป็น None โดยอัตโนมัติ)
  • Local vs Global Scope: ตัวแปรที่ประกาศในฟังก์ชันเป็น Local ภายนอกมองไม่เห็น และการเปลี่ยนค่าไม่กระทบตัวแปรข้างนอก (Pass by value สำหรับ int, float, str, tuple)
  • Default & Keyword Args: Default args ต้องอยู่ข้างหลังเสมอ เช่น def calc(x, rate=0.05): และสามารถส่งค่าแบบระบุชื่อได้ calc(rate=0.1, x=100)
  • Modules: import math (`math.pi`, `math.sqrt`) และ import random (`random.seed(100)`, `random.randint(1, 10)`, `random.uniform(-1, 1)`)

⚠️ กับดักข้อสอบ Scope & Multiple Returns 

def bump(x):
    x += 3

n = 5
bump(n)
print(n) # ได้ผลลัพธ์เป็น 5 (ไม่ใช่ 8!) เพราะ n ส่งค่าแบบ Pass by Value
💡 Multiple Returns: คืนค่าหลายตัวได้ด้วย return a, b, c เวลาเรียกรับค่าต้องเขียน x, y, z = func()

3. Tuples & Strings (ทูเพิลและสตริงก์)

▶ คลิปสอน 📄 สไลด์

📌 มโนทัศน์ที่ต้องแม่น (Key Concepts)

  • Immutability: ทั้ง String และ Tuple แก้ไขค่าตรงๆ ไม่ได้ เช่น t[0] = 9 จะเกิด Error ทันที!
  • String Slicing & Repetition:
    • "hello"[1:4] $\rightarrow$ 'ell'
    • (1, 2) * 3 $\rightarrow$ (1, 2, 1, 2, 1, 2)
  • String Methods ยอดฮิต:
    • .split(sep) แยกข้อความออกเป็น List
    • sep.join(list) รวม List กลับเป็นข้อความ
    • .upper(), .lower(), .isdigit(), .strip()

💡 ตัวอย่างข้อสอบจริง (Pattern ที่ออกบ่อย) 

temp = "10:20"
words = temp.split(":")
first = int(words[0])
second = int(words[1])
print(first + second) # Output: 30
✨ จำไว้: ผลจาก .split() ได้สมาชิกเป็น String เสมอ ต้องใช้ int() แปลงก่อนบวกเลข

4. Dictionaries (ดิกชันนารี & การนับความถี่)

▶ คลิปสอน 📄 สไลด์

📌 มโนทัศน์ที่ต้องแม่น (Key Concepts)

  • โครงสร้างคู่กุญแจ-ค่า: {key: value} คีย์ต้องไม่ซ้ำกัน (Unique) และเป็น Immutable (เช่น int, str, tuple)
  • การอัปเดตและเพิ่มข้อมูล: dict[key] = new_val ถ้ามีคีย์เดิมจะทับ ถ้ายังไม่มีจะเป็นการสร้างคีย์ใหม่
  • Pattern นับความถี่ (Frequency Counter):
    d[item] = d.get(item, 0) + 1 ออกสอบแน่นอน 100%!

💡 ตัวอย่างข้อสอบจริง (DNA Frequency) 

dna = "A C C T T G C C"
dna_list = dna.split(" ")
dna_dict = {}
for g in dna_list:
    dna_dict[g] = dna_dict.get(g, 0) + 1
print(dna_dict)
# ผลลัพธ์: {'A': 1, 'C': 4, 'T': 2, 'G': 1}
✨ วิธีคิด: ตัวแรกถ้ายังไม่มีใน Dict คำสั่ง .get(g, 0) จะคืนค่า 0 แล้วบวก 1 ทันที สะดวกและไม่เกิด KeyError

temp = "10:20"

วิธีคิด: แยกด้วย `:` ได้ `'10'` กับ `'20'` แปลงเป็น int แล้วบวกกันได้ $10 + 20 = 30$

ข้อที่ 5 Default & Keyword Arguments 
def do_something(total, rate=0.8):
    return total + 5 * rate

print(do_something(10))
print(do_something(10, 0.1))
print(do_something(rate=0.3, total=5))
14.0
10.5
6.5

วิธีคิด:
• $10 + 5(0.8) = 14.0$
• $10 + 5(0.1) = 10.5$
• $5 + 5(0.3) = 6.5$ (ส่งแบบ Keyword args สลับที่ได้)

ข้อที่ 6 Scope of Variables (Local vs Global) 
my_string = "Hello"

def do_another():
    my_string = "Hello There"
    my_string = my_string[7:]
    print(my_string * 3)

do_another()
print(my_string)
hereherehere
Hello

วิธีคิด: ในฟังก์ชันตัดได้ `'here'` คูณ 3 ได้ `'hereherehere'` แต่ตัวแปรในฟังก์ชันเป็น Local เมื่อจบฟังก์ชัน `my_string` ด้านนอกยังคงเป็น `'Hello'` เหมือนเดิม

Part 2: ข้อสอบเขียนโปรแกรมข้อใหญ่ (Linear Function & Data Generation)

ออกสอบแน่ 100%

โจทย์: จงเขียนโปรแกรมสร้างข้อมูลสองชุด $X$ และ $Y$ ตามสมการเส้นตรง $y = w \cdot x + b$ โดยสุ่ม $x \in [1, 8]$ และคำนวณผลรวมยกกำลังสองของ $X, Y$ พร้อมผลต่าง โดยแบ่งเป็น 3 ฟังก์ชันตาม Pseudocode: 

import random

def gen_data(w, b, n):
    X = []
    Y = []
    for i in range(n):
        x = random.randint(1, 8)
        y = w * x + b
        X.append(x)
        Y.append(y)
    return X, Y

def sum_squared_diff(X, Y):
    total_X = 0
    total_Y = 0
    for i in range(len(X)):
        total_X += X[i] ** 2
        total_Y += Y[i] ** 2
    return total_X, total_Y, total_X - total_Y

def main():
    random.seed(100)
    w = float(input('Enter w: '))
    b = float(input('Enter b: '))
    n = int(input('Enter n: '))
    X, Y = gen_data(w, b, n)
    X_ss, Y_ss, XY_diff = sum_squared_diff(X, Y)
    print(f"SSX = {X_ss}, SSY = {Y_ss}, Diff = {XY_diff}")

main()
