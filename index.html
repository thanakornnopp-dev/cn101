5.1 กฎเหล็กของ List Slicing (`[start:stop:step]`)

การ Slice คือการ "หั่นชิ้นส่วน" ของลิสต์ออกมาเป็นลิสต์ใหม่ โดยมีไวยากรณ์คือ my_list[start:stop:step] จำกฎสำคัญ 3 ข้อนี้ให้แม่น:

1. กฎไม่เอา Stop (Exclusive)

ตำแหน่ง `stop` จะไม่ถูกดึงมารวม เช่น `[1:4]` จะดึง index 1, 2, 3 เท่านั้น ไม่เอา index 4

2. Index ติดลบ (นับจากหลัง)

`-1` คือตัวสุดท้าย, `[-3:]` คือเอา 3 ตัวสุดท้ายจนจบ, `[:-2]` คือตัด 2 ตัวท้ายทิ้ง

3. Step กลับด้าน `[::-1]`

ถ้า step เป็น `-1` ลิสต์จะถูกอ่านย้อนกลับจากหลังมาหน้าทันที

# ตัวอย่างการทำงานจริงของ Slicing: 
nums = [10, 20, 30, 40, 50, 60]
print(nums[1:4])   # ผลลัพธ์: [20, 30, 40] (index 1, 2, 3)
print(nums[-3:])   # ผลลัพธ์: [40, 50, 60] (3 ตัวสุดท้าย)
print(nums[::-1])  # ผลลัพธ์: [60, 50, 40, 30, 20, 10] (กลับด้าน)
print(nums[::2])   # ผลลัพธ์: [10, 30, 50] (กระโดดทีละ 2 ช่อง)

5.2 Nested Lists (2D List / ตาราง 2 มิติ)

ใน Python ไม่มีชนิดข้อมูล Matrix แท้ๆ แต่เราใช้ "List ซ้อน List" ในการจำลองตาราง โดยเข้าถึงสมาชิกผ่าน matrix[row][col]: 

# สร้างตาราง 3 แถว 2 หลัก
matrix = [
    [10, 20],  # แถว index 0
    [30, 40],  # แถว index 1
    [50, 60]   # แถว index 2
]

print(matrix[0][1])  # แถว 0 หลัก 1 -> ได้ 20
print(matrix[2][0])  # แถว 2 หลัก 0 -> ได้ 50

# การวนลูปสองมิติมาตรฐาน (Row-wise Traversal):
for r in range(len(matrix)):
    for c in range(len(matrix[r])):
        print(f"แถว {r} หลัก {c} = {matrix[r][c]}")

5.3 List Comprehension (ยุบ Loop สู่บรรทัดเดียว)

หัวข้อนี้ถูกออกแบบมาเพื่อลดความเยิ่นเย้อของโค้ด loop ปกติ โดยมีรูปแบบไวยากรณ์ที่ต้องแยกให้ออกในห้องสอบ:

แบบที่ 1: มีแค่ if (กรองข้อมูล - if อยู่ท้ายสุด) 
# ต้องการเฉพาะเลขคู่แล้วยกกำลังสอง
# รูปแบบ: [expression for item in iterable if condition]
evens_squared = [x**2 for x in range(10) if x % 2 == 0]
# ผลลัพธ์: [0, 4, 16, 36, 64]
แบบที่ 2: มี if-else (แปลงค่า - if-else ต้องย้ายมาไว้ข้างหน้า for!) 
# ถ้าเลขคู่ใส่ 'even' ถ้าเลขคี่ใส่ 'odd'
# รูปแบบ: [exp1 if condition else exp2 for item in iterable]
labels = ['even' if x % 2 == 0 else 'odd' for x in range(5)]
# ผลลัพธ์: ['even', 'odd', 'even', 'odd', 'even']

6.1 สถาปัตยกรรมของฟังก์ชัน (Header vs Body) และการกระโดด Control Flow

ฟังก์ชันประกอบด้วย 2 ส่วน: Function Header (`def name(params):`) และ Body (ย่อหน้าคำสั่งข้างใน) เมื่อมีการเรียกฟังก์ชัน (Call) ตัวแปลภาษาจะกระโดดไปทำงานที่ฟังก์ชันนั้น และเมื่อเสร็จสิ้น (เจอ return หรือบรรทัดสุดท้าย) จะกระโดดกลับมาทำงานที่บรรทัดถัดไปทันที

Void Functions (ไม่มี Return)

ทำงานตามคำสั่งแล้วจบไป ไม่ได้ส่งค่ากลับคืนมา เทคนิคอลใน Python ฟังก์ชันเหล่านี้จะคืนค่าเป็น None โดยอัตโนมัติ 

def say_hi(name):
    print("Hi", name)

res = say_hi("Chokie")
print(res) # ได้ผลลัพธ์เป็น None
Value-Returning Functions (มี Return)

ต้องมีคำสั่ง return expression ส่งค่าออกไปให้ภายนอกนำไปใช้งานหรือคำนวณต่อได้ 

def square(n):
    return n ** 2

ans = square(5)
print(ans + 10) # 25 + 10 = 35

6.2 ขอบเขตตัวแปร (Scope: Local vs Global) และการส่งผ่านค่า (Pass by Value)

นี่คือ "หัวข้อที่ออกข้อสอบ Tracing หลอกคะแนนมากที่สุด" จำกฎ 2 ข้อนี้ให้ขึ้นใจ:

⚠️ กฎทองเรื่อง Local Scope & Pass by Value: 
def change_val(x):
    x = 100
    print("ในฟังก์ชัน:", x)

x = 5
change_val(x)
print("นอกฟังก์ชัน:", x)

ผลลัพธ์ที่พิมพ์:

ในฟังก์ชัน: 100
นอกฟังก์ชัน: 5

คำอธิบาย: ตัวแปรจำนวนเต็มถูกส่งแบบ Pass by Value (ก็อปปี้ค่าไปให้) ตัวแปร `x` ในฟังก์ชันเป็นคนละตัวกับ `x` ด้านนอก การเปลี่ยนค่าข้างในจึงไม่ส่งผลกระทบต่อภายนอกเด็ดขาด!

6.3 พารามิเตอร์เริ่มต้น (Default) และ Keyword Arguments

Default Arguments

พารามิเตอร์ที่มีค่า Default ต้องอยู่ทางขวาสุดเสมอ:

def fee(amount, rate=0.07):
    return amount * rate

print(fee(100))      # ใช้ default rate = 7.0
print(fee(100, 0.1)) # ส่งทับได้ rate = 10.0
Keyword Arguments

สามารถเรียกใช้งานโดยระบุชื่อพารามิเตอร์เพื่อสลับที่ได้:

def info(name, age):
    print(f"{name} is {age}")

# ระบุชื่อ สลับลำดับได้ ผลลัพธ์เหมือนเดิม
info(age=20, name="Somsak")

6.4 โมดูลมาตรฐาน: `math` และ `random` 

import math
import random

# Math Module:
print(math.pi)              # 3.141592653589793
print(math.sqrt(16))        # 4.0 (ถอดราก)
print(math.hypot(3, 4))     # 5.0 (ปีทาโกรัส sqrt(3^2 + 4^2))
rad = math.radians(90)      # แปลงองศาเป็นเรเดียน ก่อนใส่ในตรีโกณ!
print(math.cos(rad))        # cos(90) ~ 0.0

# Random Module:
random.seed(100)            # ล็อกชุดตัวเลขสุ่มให้ตรงกับเฉลยอาจารย์
print(random.randint(1, 5)) # สุ่มจำนวนเต็มช่วง 1 ถึง 5 (รวมทั้ง 1 และ 5!)
print(random.uniform(-1, 1))# สุ่มทศนิยมระหว่าง -1.0 ถึง 1.0

7.1 ทำความเข้าใจความเป็น "Immutable" (ห้ามแตะต้องภายใน)

คำว่า Immutable แปลตรงตัวว่า "เปลี่ยนรูปไม่ได้" เมื่อสร้าง String หรือ Tuple ขึ้นมาในหน่วยความจำแล้ว เราจะไม่สามารถสั่งแก้ค่ารายตัวได้ เช่น: 

s = "Hello"
# s[0] = "J"   <-- จะเกิด TypeError ทันที!

t = (1, 2, 3)
# t[0] = 99    <-- จะเกิด TypeError ทันที!

# ทางแก้ที่ถูกต้องคือการสร้าง Object ใหม่ขึ้นมาแทน:
s = "J" + s[1:]       # "Jello"
t = (99,) + t[1:]     # (99, 2, 3)

7.2 เจาะลึก String Methods (อาวุธสำคัญในข้อสอบ)

1. .split() vs .join()

สองคำสั่งคู่บุญที่ทำงานตรงข้ามกัน:

raw = "apple,banana,orange"
fruits = raw.split(",")
# fruits = ['apple', 'banana', 'orange']

joined = " | ".join(fruits)
# joined = "apple | banana | orange"
2. .strip() และ .isdigit()

ใช้สำหรับคลีนข้อมูลก่อนประมวลผล:

txt = "   12345 \n"
cleaned = txt.strip()     # "12345"
print(cleaned.isdigit())  # True

# ถ้ามีตัวอักษรปน .isdigit() จะคืนค่า False:
print("12a45".isdigit())  # False

7.3 การจัดรูปแบบข้อความด้วย f-string

อ.นัท เน้นมากเรื่องการจัดทศนิยมและช่องว่างในคำสั่ง `print()`: 

val = 123.4567
print(f"{val:.2f}")     # '123.46' (ปัดทศนิยม 2 ตำแหน่ง)
print(f"{val:10.2f}")   # '    123.46' (ความกว้าง 10 ช่อง ชิดขวา)
num = 1000000
print(f"{num:,}")       # '1,000,000' (ใส่เครื่องหมายจุลภาคคั่นหลักพัน)

บทที่ 8: Dictionaries (ดิกชันนารี & การนับความถี่)

▶ คลิปบรรยาย 📄 สไลด์ PDF

8.1 โครงสร้าง Key-Value และข้อห้ามสำคัญของ Key

Dictionary เก็บข้อมูลเป็นคู่ {key: value} คล้ายสารบัญหรือสมุดโทรศัพท์ โดยมีกฎเหล็กว่า:

  • Key ต้องไม่ซ้ำกัน (Unique): ถ้าสั่งเขียนค่าทับคีย์เดิม มันจะเปลี่ยนค่า Value ของคีย์นั้นทันที ไม่สร้างแถวใหม่
  • Key ต้องเป็น Immutable เท่านั้น: ใช้ `int`, `float`, `str`, `tuple` เป็น Key ได้ แต่ ห้ามใช้ List หรือ Dict เป็น Key เด็ดขาด (เพราะลิสต์เปลี่ยนแปลงค่าได้ ทำให้หาแฮชไม่ได้)
  • Value เป็นข้อมูลชนิดใดก็ได้ (เป็นตัวเลข, ข้อความ, หรือแม้กระทั่ง List ก็ได้)

8.2 การเข้าถึงค่าอย่างปลอดภัยด้วย .get() ป้องกัน KeyError 

prices = {'apple': 30, 'banana': 20}

# แบบที่ 1: ดึงตรงๆ ด้วยก้ามปู (เสี่ยงพัง!)
# print(prices['orange'])   <-- จะเกิด KeyError ทันทีเพราะไม่มี 'orange'

# แบบที่ 2: ดึงอย่างปลอดภัยด้วย .get() (แนะนำในข้อสอบ)
print(prices.get('orange', 0)) # คืนค่า 0 โดยไม่เกิด Error เลย!

8.3 การวนลูปใน Dictionary และกระบวนท่า Frequency Counter

ในห้องสอบ อาจารย์จะให้ข้อความหรือลิสต์มา แล้วสั่งให้นับจำนวนความถี่ เช่น นับจำนวนเกรด A, B, C หรือนับรหัส DNA ให้ใช้สูตรสำเร็จ 3 บรรทัดนี้เสมอ:

🌟 พระเอกของบทนี้: Frequency Counter Pattern 
data = ['A', 'C', 'C', 'T', 'T', 'G', 'C', 'C']
counts = {}

for item in data:
    # ถ้ายังไม่มีให้เริ่มที่ 0 แล้วบวก 1 ทันที
    counts[item] = counts.get(item, 0) + 1

print(counts)
# ได้ผลลัพธ์: {'A': 1, 'C': 4, 'T': 2, 'G': 1}

# การวนลูปแสดงผลลัพธ์คู่คีย์-ค่า:
for item, qty in counts.items():
    print(f"รหัส {item} พบจำนวน {qty} ครั้ง")

จุดที่ข้อสอบชอบถามความแตกต่างและดักคะแนนมากที่สุด

ออกสอบชัวร์
ชนิดข้อมูล (Type) สัญลักษณ์ Syntax แก้ไขค่าได้ไหม? (Mutable) มีลำดับ Index ไหม? (Ordered) ค่าซ้ำได้ไหม? (Duplicates) ข้อควรระวังในห้องสอบ ⚠️
List [1, 2, 3] ได้ (Mutable) มี (0, 1, 2...) ซ้ำได้ `.append()` คืนค่า `None` (อย่าเขียน `x = x.append(...)`)
Tuple (1, 2, 3) ไม่ได้ (Immutable) มี (0, 1, 2...) ซ้ำได้ ถ้ามีตัวเดียวต้องมีจุลภาค (9,), แก้ค่าตรงๆ เช่น t[0] = 5 Error!
Dictionary {'a': 1, 'b': 2} ได้ (Mutable) เข้าถึงผ่าน Key Key ห้ามซ้ำ, Value ซ้ำได้ ดึงค่าที่ไม่มีคีย์ด้วย `d[k]` เกิด KeyError ต้องใช้ d.get(k, 0)
Set {1, 2, 3} ได้ (Mutable) ไม่มี Index ห้ามซ้ำเด็ดขาด เซ็ตว่างต้องเขียน set() (เขียน `{}` จะกลายเป็น dict ว่าง!)

⚡ รวม Methods & Functions ที่ออกข้อสอบบ่อยที่สุด (High-Yield Cheat Sheet)

🔤 String Methods

  • .split(sep)

    ตัดข้อความเป็น List (ค่า default คือช่องว่าง)

  • sep.join(list)

    รวม List เป็น String (สมาชิกต้องเป็น string ทั้งหมด!)

  • .strip()

    ตัดช่องว่างหน้า-หลัง

  • .upper() / .lower()

    แปลงตัวพิมพ์ใหญ่/เล็ก

  • .isdigit()

    เช็คว่าเป็นตัวเลข 0-9 หรือไม่

📋 List Methods

  • .append(x)

    เพิ่มท้ายลิสต์ (คืนค่า None)

  • .insert(i, x)

    แทรก x ลงที่ index i

  • .pop(i)

    ดึงตัวที่ i ออกและคืนค่านั้น

  • sorted(x) vs .sort()

    sorted() คืนลิสต์ใหม่ ส่วน .sort() แก้ลิสต์เดิมและคืนค่า None!

  • len(x), sum(x), min, max

    ฟังก์ชันพื้นฐานหาความยาว ผลรวม

📖 Dict Methods

  • d[k] = v

    เพิ่มหรือเขียนทับค่าของคีย์ k

  • d.get(k, default)

    ดึงค่า ถ้าไม่มีให้คืนค่า default ไม่พัง!

  • d.keys() / .values()

    ดึงเฉพาะคีย์ทั้งหมด / เฉพาะค่าทั้งหมด

  • for k, v in d.items():

    วนลูปดึงคู่ (Key, Value) พร้อมกัน

  • k in d

    ตรวจสอบว่ามี Key ชื่อ k หรือไม่

🎲 Math & Random

  • math.pi

    ค่าคงที่ $\pi \approx 3.14159$

  • math.sqrt(x), hypot(a,b)

    ถอดราก และหาด้านตรงข้ามมุมฉาก

  • random.seed(100)

    ล็อกจุดตั้งต้นการสุ่ม ให้ผลลัพธ์ตรงกับเฉลย

  • random.randint(a, b)

    สุ่มจำนวนเต็มช่วง [a, b] (รวมทั้ง a และ b!)

  • random.uniform(a, b)

    สุ่มทศนิยมระหว่าง a และ b

ท่องให้ขึ้นใจ ตรวจสอบให้ครบทุกบรรทัด เพื่อป้องกันการโดนหักคะแนนโดยไม่จำเป็น!

1
เช็คเครื่องหมาย Colon ( : ) หลัง `def`, `for`, `while`, `if`, `elif`, `else` มีเครื่องหมาย `:` ครบทุกบรรทัดหรือไม่?
2
เช็คการย่อหน้า (Indentation) คำสั่งในบล็อกฟังก์ชันหรือบล็อกลูป ต้องย่อหน้าเข้าไปเป็นระเบียบชัดเจน
3
เช็คการแปลง Type ตัวเลข ค่าที่มาจาก `input()` หรือ `.split()` เป็น String เสมอ แปลงด้วย `int()` หรือ `float()` หรือยัง?
4
เช็คคำสั่ง return vs print ถ้าโจทย์สั่งว่า *"ให้คืนค่า (return)"* ห้ามเขียน `print()` เด็ดขาด ต้องมีคำสั่ง `return` ชัดเจน
5
เช็คตัวแปรรับค่า Multiple Return ถ้าฟังก์ชัน `return a, b` เวลารับค่าต้องเขียน `x, y = func()` ให้จำนวนตัวแปรตรงกัน
6
เช็คการเรียกฟังก์ชัน main() บรรทัดสุดท้ายของไฟล์ต้องมี `main()` ชิดซ้ายสุด เพื่อเป็นตัวเริ่มโปรแกรม
7
เช็คฟอร์แมต Output ให้ตรงตัวอย่าง สังเกตทศนิยมกี่ตำแหน่ง เช่น `f"{val:.2f}"`, เครื่องหมายคั่น เช่น `print(x, end=', ')` หรือเว้นบรรทัดใหม่

ข้อที่ 1 Tuple & List Slicing 
my_list = [10, 50, 30, 5, 7]
your_list = tuple(my_list[3:]) * 3
print(your_list)
print(min(my_list), max(your_list))
(5, 7, 5, 7, 5, 7)
5 7

วิธีคิด: `my_list[3:]` คือ `[5, 7]` แปลงเป็น Tuple `(5, 7)` แล้วคูณ 3 จะเบิ้ล 3 รอบ `(5, 7, 5, 7, 5, 7)` บรรทัดสอง `min` คือ 5 และ `max` คือ 7

ข้อที่ 2 2D List Manipulation 
numbers = [[1, 5], [6, 7]]
numbers[0][0] = 9
numbers[1][1] = 10
print(numbers)
[[9, 5], [6, 10]]

วิธีคิด: แถว 0 หลัก 0 เปลี่ยนจาก 1 เป็น 9, แถว 1 หลัก 1 เปลี่ยนจาก 7 เป็น 10

ข้อที่ 3 String split & List append 
list1 = "aa bb cc".split()
list1.append("xx")
list1[0] = "k"
print(list1)
['k', 'bb', 'cc', 'xx']

วิธีคิด: `.split()` แยกช่องว่างได้ `['aa', 'bb', 'cc']` เติม `'xx'` ต่อท้าย แล้วแก้ตัวแรกจาก `'aa'` เป็น `'k'`

ข้อที่ 4 Custom Delimiter & Type Casting 
temp = "10:20"
words = temp.split(":")
first = int(words[0])
second = int(words[1])
print(first + second)
30

วิธีคิด: แยกด้วย `:` ได้ `'10'` กับ `'20'` แปลงเป็น int แล้วบวกกันได้ $10 + 20 = 30$

ข้อที่ 5 Default & Keyword Arguments 
def do_something(total, rate=0.8):
    return total + 5 * rate

print(do_something(10))
print(do_something(10, 0.1))
print(do_something(rate=0.3, total=5))
14.0
10.5
6.5

วิธีคิด: $10 + 5(0.8) = 14.0$, $10 + 5(0.1) = 10.5$, $5 + 5(0.3) = 6.5$ (ส่งแบบ Keyword args สลับที่ได้)

ข้อที่ 6 Scope of Variables (Local vs Global) 
my_string = "Hello"

def do_another():
    my_string = "Hello There"
    my_string = my_string[7:]
    print(my_string * 3)

do_another()
print(my_string)
hereherehere
Hello

วิธีคิด: ในฟังก์ชันตัดได้ `'here'` คูณ 3 ได้ `'hereherehere'` แต่ตัวแปรในฟังก์ชันเป็น Local เมื่อจบฟังก์ชัน `my_string` ด้านนอกยังคงเป็น `'Hello'` เหมือนเดิม

Part 2: ข้อสอบเขียนโปรแกรมข้อใหญ่ (Linear Function & Data Generation)

ออกสอบแน่ 100%

โจทย์: จงเขียนโปรแกรมสร้างข้อมูลสองชุด $X$ และ $Y$ ตามสมการเส้นตรง $y = w \cdot x + b$ โดยสุ่ม $x \in [1, 8]$ และคำนวณผลรวมยกกำลังสองของ $X, Y$ พร้อมผลต่าง โดยแบ่งเป็น 3 ฟังก์ชันตาม Pseudocode: 

import random

def gen_data(w, b, n):
    X = []
    Y = []
    for i in range(n):
        x = random.randint(1, 8)
        y = w * x + b
        X.append(x)
        Y.append(y)
    return X, Y

def sum_squared_diff(X, Y):
    total_X = 0
    total_Y = 0
    for i in range(len(X)):
        total_X += X[i] ** 2
        total_Y += Y[i] ** 2
    return total_X, total_Y, total_X - total_Y

def main():
    random.seed(100)
    w = float(input('Enter w: '))
    b = float(input('Enter b: '))
    n = int(input('Enter n: '))
    X, Y = gen_data(w, b, n)
    X_ss, Y_ss, XY_diff = sum_squared_diff(X, Y)
    print(f"SSX = {X_ss}, SSY = {Y_ss}, Diff = {XY_diff}")

main()
