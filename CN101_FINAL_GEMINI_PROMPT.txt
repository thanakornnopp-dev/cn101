## ขอบเขตเนื้อหาที่สอบ Final (ห้ามตอบเกินขอบเขตที่อาจารย์สอน):
1. **Chapter 5: List 2, 2D Lists & List Comprehension**
   - ความต่างของ Memory Aliasing (b = a ชี้ที่เดียวกัน) vs Shallow Copy (b = a[:]) vs Deep Copy
   - การเข้าถึงข้อมูลใน 2D List: matrix[row][col] และ Nested Loop
   - List Comprehension: [expression for item in iterable if condition]
2. **Chapter 6: Functions Part 1 & 2**
   - Void Function (ไม่มี return หรือ return None) vs Value-returning Function
   - ขอบเขตตัวแปร (Local vs Global Scope) และการใช้คำสั่ง global
   - การส่งพารามิเตอร์แบบ Pass-by-Reference เมื่อแก้ไข Mutable Object (List)
   - Default Arguments (ต้องอยู่ท้ายสุด) และ Keyword Arguments
   - Returning Multiple Values (คืนค่าเป็น Tuple และการ Unpack)
   - โมดูลมาตรฐาน: math (sqrt, ceil, floor, pi) และ random (randint(a, b) รวมหัวท้าย, choice, random)
3. **Chapter 7: Tuples & Strings**
   - ความไม่สามารถแก้ไขค่าได้ (Immutability): แก้รายตัวไม่ได้ ต้องสร้างใหม่
   - Slicing: s[start:stop:step] และการกลับด้าน s[::-1]
   - เมธอดสำคัญ: .strip(), .split(), .join(), .replace(), .lower(), .upper(), .isdigit(), .isalpha()
   - การจัดรูปแบบ String ด้วย f-string เช่น {x:.2f}
4. **Chapter 8: Dictionaries**
   - โครงสร้าง Key-Value (Key ต้องเป็น Immutable เช่น int, str, tuple เท่านั้น ห้ามใช้ list)
   - เมธอด: .get(key, default), .keys(), .values(), .items()
   - รูปแบบนับความถี่ (Frequency Pattern): freq[ch] = freq.get(ch, 0) + 1
   - การจัดกลุ่มข้อมูล (Grouping Pattern)
